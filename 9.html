Estimating Cell Size

A microscope can turn an invisible cell into a measurable object. By comparing the visible field diameter with the number of cells across it, we can estimate the size of one cell.

Block 9: Estimating Cell Size — Formula

Unit conversion:
1 millimetre (mm) = 1000 micrometre (µm)

Formula:

Estimated size of cell = Diameter of visible field (µm) ÷ Number of cells along the diameter

Example:

  • Diameter of field = 5000 µm
  • Cells along diameter = 25
  • Size of one cell = 5000 ÷ 25 = 200 µm
